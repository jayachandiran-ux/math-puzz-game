# 🧩 Math Puzz

An interactive browser-based math puzzle game built using **HTML, CSS, and JavaScript**.

Players solve arithmetic questions, unlock stages, complete levels, and improve their calculation skills through an engaging game experience.

## ✨ Features

- 🎮 10 Progressive Levels
- 🔓 Stage Unlocking System
- ➕ Addition Challenges
- ➖ Subtraction Challenges
- ✖ Multiplication Challenges
- ➗ Division Challenges
- 🎲 Random Question Generation
- 📱 Responsive Design
- 🎨 Animated User Interface
- ✔ Correct & Wrong Result Screens
- 🏆 Level Completion Animation

## 🎮 Game Flow

```
Home Screen
      ↓
Select Level
      ↓
Select Stage
      ↓
Solve Question
      ↓
Correct?
 ┌───────────────┐
 │ Yes           │
 │               │
 │ Unlock Stage  │
 │       ↓       │
 │ Next Stage    │
 └───────────────┘
        │
        ▼
Complete Level
        │
Unlock Next Level
```

---

## 📊 Levels

There are **10 Levels**.

Each level contains **4 Stages**.

| Stage | Operation |
|--------|-----------|
| Stage 1 | Addition |
| Stage 2 | Subtraction |
| Stage 3 | Multiplication |
| Stage 4 | Division |
